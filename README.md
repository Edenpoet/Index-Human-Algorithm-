## About

Cognition Illustrations is an experimental visual archive documenting handmade index card illustrations, patterns, and symbolic constructions.

Each index card represents an individual visual record. Together, the cards form a growing collection exploring neural pathways, cognition, variables, and the representation of mental processes through visual forms.

The project uses the index card as an independent unit of documentation, allowing each illustration to exist as its own record while contributing to a larger collection.

## Concept

The archive is built around several conceptual elements:

- **Cognition:** Visual interpretations and illustrations associated with processes of thought.
- **Neural Pathways:** Patterns, connections, structures, and pathways represented through handmade illustrations.
- **Variables:** Individual elements, configurations, and variations recorded across index cards.
- **Telemetry of the Mind:** A conceptual approach to documenting individual processes through visual records.

## Archive Structure

Each index card is treated as an individual record within the collection.

The archive may contain:

- Handmade illustrations and patterns.
- Visual symbols and glyphs.
- Repeated or evolving configurations.
- Individual card variations.
- Photographic documentation.
- Metadata and descriptive records.

## Purpose

The purpose of this project is to create an ongoing archive of handmade visual records.

Rather than treating each card as an isolated drawing, the collection considers each card an individual unit within a larger system of visual documentation.

The archive is intended to grow organically through continued experimentation, illustration, observation, and cataloging.
